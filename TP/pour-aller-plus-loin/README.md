## Usage recommandé

Ces fiches sont utiles après le parcours principal pour :

- observer un incident de réplication Kafka ;
- provoquer et lire un lag consommateur durable ;
- étudier les rejets métier en détail ;
- comparer `at most once`, `at least once` et `exactly_once_kafka` ;
- discuter montée en charge, temporisation et perturbations réseau ;
- relier les métriques Grafana aux phénomènes Kafka observés.
